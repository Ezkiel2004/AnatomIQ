3D Anatomy WebGL Architecture

AnatomIQ utilizes a production-grade Three.js WebGL engine featuring real-time OrbitControls, raycasting mesh picking, dynamic lighting rigs, and automated THREE.Box3 bounding-box model auto-centering.

GLB/GLTF Drop-in Pipeline: To introduce production photorealistic anatomical models, place standard .glb files into uploads/models/{system_code}.glb (e.g. skeletal.glb, circulatory.glb). The dynamic loader detects, auto-centers, and frames them automatically without code changes.
Current Placeholder Mode: Procedural 3D anatomical mannequins built with modular Three.js geometry groups, material caching, interactive structure inspection, and layer toggles.
